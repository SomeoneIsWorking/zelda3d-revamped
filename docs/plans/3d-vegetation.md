# Real 3D grass and vines

User, 2026-11-27 (Fedora): "Two mod plans for much later:

* Vegetation aka real 3D grass
* 3D vines instead of flat textures"

Scheduled for much later, after the current reports.

- **Vegetation:** grass drawn as real 3D blades where the game draws a flat grass texture on the ground.
- **Vines:** vines as 3D geometry where the game draws a flat vine texture (for example the climbable
  vine walls and the hanging vines inside the Deku Tree, `docs/issues/deku-vines.md`).
